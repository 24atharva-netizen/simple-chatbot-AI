# Simple AI Chatbot

## Project Description
This is a simple rule-based chatbot developed using Python. The chatbot interacts with users and provides predefined responses based on user input.

## Features
- Responds to greetings
- Answers simple questions
- Exits when the user types "bye"
- Easy to understand and use
